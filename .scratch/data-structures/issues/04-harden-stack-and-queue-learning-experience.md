# 04: Harden the Stack and Queue learning experience

**What to build:** Every learner can reliably author, inspect, and replay the completed Stack and
Queue experience, including when labels repeat, a Structure change would discard a draft, or the
workbench is used with keyboard, assistive technology, or reduced motion.

**Blocked by:** 02 — Add Queue operation-sequence learning path; 03 — Synchronize structured and text sequence authoring.

**Status:** completed

- [x] Equal labels receive stable conditional Occurrence badges and accessible descriptions only
  while their Value occurrences coexist; unique labels remain uncluttered.
- [x] Changing between Stack and Queue confirms a non-empty draft before replacing it with a new
  empty Operation sequence and never silently translates operations.
- [x] Non-color cues, keyboard control, textual visual-state equivalents, meaningful live
  announcements, and reduced-motion behavior cover authoring and playback; regression coverage
  verifies stale-response protection, catalog compatibility, validation, and the complete suite.
